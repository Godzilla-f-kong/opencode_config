# Better Compact 来源

运行文件基于 Better Compact 0.2.5 的基础提交 `105ce9cfeb8e207c8c2abd55096c89a6db442c28` 构建，并叠加本地 Windows directory fsync 修复。

在仓库根目录执行以下命令构建：

```text
pnpm --filter better-compact build
```

源码获取地址：<https://github.com/AshishKumar4/better-compact/tree/105ce9cfeb8e207c8c2abd55096c89a6db442c28>。
本地修复补丁：`windows-directory-fsync.patch`。
